# Kyutai voice licenses - commercial use audit

Generated by reading the license documentation in the `kyutai/tts-voices` Hugging Face repo's own README.md (one license per dataset folder, explicitly documented by Kyutai - much more authoritative than Piper's per-voice MODEL_CARD guesswork). 901 voices total (the `.safetensors` embedding files `--all-voices` actually iterates over for the TTS 1.6B model this script uses).

**Not legal advice.** Best-effort audit of publicly stated licenses; verify anything you plan to rely on commercially yourself, especially the 3 "unclear" voices.

**Summary: 641 commercial-safe, 257 non-commercial, 3 unclear.**

## Critical: the default English voice is NOT commercial-safe

`expresso/ex03-ex01_happy_001_channel1_334s.wav` - **the script's default `--language en` voice** (`DEFAULT_VOICE_BY_LANGUAGE["en"]` in `tts_batch/backends/kyutai.py`) - comes from the Expresso dataset, licensed CC BY-NC 4.0 (**non-commercial use only**), per Kyutai's own repo README. The default French voice (`cml-tts/fr/10087_11650_000028-0002.wav`) is CC BY 4.0 and already commercial-safe.
